# Code & Copper

Copiloto de campo y estudio del integrador tecnológico. Calculadoras de baja tensión (REBT), clima (RITE y gases fluorados) y diagnóstico, pensadas para el móvil y para funcionar sin cobertura.

Normativa española y europea: 230/400 V, 50 Hz, secciones en mm². Los datos tabulados llevan fecha de contraste en Ajustes.

## Desarrollo

Requiere Node 24 y pnpm 10.

```bash
pnpm install
pnpm dev
pnpm test
pnpm check
pnpm build
pnpm preview
```

La app se publica en [edvincodes.github.io/code-and-copper](https://edvincodes.github.io/code-and-copper/).
